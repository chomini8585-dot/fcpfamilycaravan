# 중고차 매물 등록 방법

홈페이지 주소: https://familycaravan.net/used-cars/

`cars` 폴더 안에 **번호 폴더**를 만들고, 그 안에 **사진**과 **info.txt**를 넣어 올리면
앨범에 자동으로 나옵니다. 페이지 코드는 건드리지 않습니다.

```
used-cars/
  cars/
    _양식/info.txt   ← 복사해서 쓰는 빈 양식 (홈페이지에는 안 나옴)
    01/
      info.txt
      사진들 (이름 아무거나)
    02/
    03/ …
```

## 새 차량 올리기

1. **번호 정하기** — 마지막 번호 다음 번호로 폴더 이름을 정합니다. **반드시 두 자리**로 씁니다:
   `01`, `02` … `09`, `10`, `11` … (`1`이 아니라 `01`) — 번호가 클수록 앨범 앞쪽에 나옵니다.
2. **사진 넣기** — 휴대폰 사진을 **이름 그대로** 넣으면 됩니다.
   - 올리고 1~3분 뒤 GitHub가 자동으로 **압축(1600px) · 위치정보 삭제 · 1.jpg, 2.jpg … 번호 정리**를 합니다.
   - 순서는 파일 이름순(휴대폰 사진은 찍은 순서)입니다.
   - 아이폰 사진(HEIC), PNG도 자동으로 JPG로 바뀝니다.
3. **대표 사진** (앨범에 나오는 사진) — 둘 중 편한 방법으로:
   - 올리기 전에 그 사진 이름을 **`대표.jpg`** 로 바꿔 두기 → 자동으로 1번 사진이 됩니다.
   - 또는 info.txt에 **`대표사진: 3`** 처럼 번호 쓰기 (상세 화면의 `3 / 12` 숫자 기준).
   - 아무것도 안 하면 1번 사진이 대표입니다.
4. **info.txt 쓰기** — `_양식/info.txt`를 복사해서 `:` 뒤에 내용을 채웁니다.
5. **GitHub에 올리기** — GitHub 웹에서 `used-cars/cars` 폴더로 들어가 **Add file → Upload files**에
   번호 폴더째 끌어다 놓고 **Commit changes**. (GitHub Desktop으로 올려도 됩니다.)
   1~3분 뒤 사진 정리까지 끝나면 앨범에 나옵니다 (새로고침).

## info.txt 쓰는 법

```
차량명: 기아 카니발 하이리무진 9인승
연식: 2022년 5월
주행거리: 35,000km
연료: 디젤
변속기: 자동
색상: 화이트
인승: 9인승
사고유무: 무사고
원가격: 6,200만원
판매가격: 4,890만원
상태: 판매중
대표사진: 1
유튜브: https://youtu.be/영상주소
---
여기부터는 상세 설명을 자유롭게 씁니다.
줄바꿈도 그대로 나옵니다.
```

- 표는 **모든 차량이 같은 칸**으로 나옵니다. 비워 둔 칸은 `-`로 표시되고, 판매가격을 비우면 `가격 상담`으로 나옵니다.
- `원가격`을 쓰면 판매가격 옆에 줄 그어서 보여 줍니다.
- `상태`는 `판매중` / `예약중` / `판매완료` 중 하나로 씁니다.
- `유튜브`에 영상 주소(유튜브 앱의 **공유 → 링크 복사**)를 붙이면 상세 화면에 영상이 나오고, 앨범 카드에 **▶ 영상** 표시가 붙습니다. 없으면 비워 두세요.
- `---` 아래가 상세 설명입니다.
- 메모장에서 저장할 때 인코딩은 **UTF-8**(기본값)로 두세요.

## 판매가 끝나면

차량 폴더를 지우지 말고 info.txt의 `상태: 판매완료`로 바꾸면 사진에 "판매완료"가 표시됩니다.
지우고 싶다면 폴더를 삭제해도 됩니다.

## 사진 추가 · 삭제

- **추가**: 그 차량 폴더에 사진을 더 올리면 뒤 번호로 붙습니다.
- **삭제**: 사진을 지우면 다음 자동 정리 때 번호가 다시 1, 2, 3 … 으로 맞춰지고 대표사진 번호도 같이 맞춰집니다.

## 특정 차량 링크 보내기

차량 상세 화면의 **링크 복사** 버튼을 누르면 그 차량이 바로 열리는 주소가 복사됩니다
(예: `https://familycaravan.net/used-cars/#car-07`). 카톡으로 보내면 됩니다.

## 자동 정리가 안 될 때

GitHub 저장소 위쪽 **Actions** 탭 → **중고차 사진 자동 정리** 에서 실행 기록을 볼 수 있습니다.
빨간 ✕가 있으면 그 기록을 열어 보거나 담당자에게 알려 주세요.
